# A-Node güncellemeleri

A-Node okul yoklama programının kurulum dosyaları **Releases** bölümündedir.

`surum.json`: A-Node bu dosyaya bakarak yeni sürüm olup olmadığını öğrenir. Kaynak kod bu depoda değildir.

Yeni sürüm yayımlama sırası: önce kurulum dosyası **Releases**'e (pre-release işaretlemeden), sonra `surum.json`.
